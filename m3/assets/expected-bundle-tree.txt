What each is for
----------------

databricks.yml          The bundle declaration. Read it with
                        assets/databricks.yml.annotated beside you.

resources/
  sample_job.job.yml    The job: three tasks, a daily trigger, and two job
                        parameters carrying the bundle variables.
  m3demo_etl.pipeline.yml
                        A serverless Lakeflow declarative pipeline, referenced
                        by the third task of the job.

src/
  sample_notebook.ipynb Executed by the first task.
  m3demo/               The Python package. main.py is the entry point the
                        second task calls after the wheel is built.
  m3demo_etl/           Pipeline sources. transformations/ holds the files the
                        pipeline picks up through its libraries glob;
                        explorations/ is excluded by .gitignore.

pyproject.toml          Package metadata, the "main" entry point, and the dev
                        dependency group. The artifacts block in databricks.yml
                        builds this with `uv build --wheel`.

tests/                  pytest tests over src/, used in Module 5. Not deployed.
fixtures/               Sample data for those tests. Not deployed.
.vscode/                Editor settings. No effect on deployment.
AGENTS.md, CLAUDE.md    Instructions for coding agents. No effect on deployment.
.gitignore              Excludes .databricks/, build/, dist/, .venv/, scratch/
                        and **/explorations/**.

Differences worth investigating
-------------------------------

Older CLI versions generate a different project entirely: a notebooks/
directory, a job keyed <project>_job rather than sample_job, no pipeline
resource, and no pyproject.toml. If your tree looks like that, check
`databricks --version`; this course requires v1.3.0 or later.
